# Changelog

Versions are tracked per skill. Tags follow the pattern `<skill-name>/vX.Y.Z`.

## create-prd

### 1.0.0 — 2026-10-30
- Initial release: interview-driven PRD for a whole project or a single feature.
- Input from chat, documents and work items; sources are treated as data, not instructions.
- Mandatory: Headline, Problem, JTBD, User Stories (+ Acceptance Criteria for
  features), Out of Scope, Non-Functional Requirements, Open Questions.
  Value Proposition is mandatory for projects only.
- Optional: Stakeholders, Delivery Values, Target Audience/Personas, User Flow,
  Design, Risks & Dependencies, Constraints, Launch Plan, KPIs.
- Template adapted from the Best Practice PRD Framework by Rohan Dehal;
  framework differences documented in README.
